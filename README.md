# Bianca's Kitchen

A searchable personal cookbook designed for GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example, `biancas-kitchen`).
2. Upload `index.html` to the root of the repository and commit it.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the published Pages URL after deployment.

No build tools or dependencies are required.
